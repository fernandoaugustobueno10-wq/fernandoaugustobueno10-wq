## 📂 Projetos

### 🔧 Sistema de Manutenção de Equipamentos
Aplicação web desenvolvida em equipe para gerenciamento de solicitações de manutenção de equipamentos.

- Desenvolvimento com Angular e Spring Boot.
- Integração com banco de dados PostgreSQL.
- Implementação de funcionalidades de clientes, funcionários e solicitações.
- Utilização de APIs REST e arquitetura em camadas.

**Tecnologias:** Java, Spring Boot, Angular, TypeScript e PostgreSQL.

### 📅 Sistema de Agendamento de Reuniões
Projeto acadêmico para criação e gerenciamento de reuniões, participantes, horários e disponibilidades.

- Modelagem de entidades e relacionamentos.
- Persistência de dados utilizando JDBC e MySQL.
- Organização do código utilizando orientação a objetos e padrão DAO.
- Gerenciamento de dependências com Maven.

**Tecnologias:** Java, JDBC, MySQL e Maven.

### 📊 Data Warehouse para Análise de Vendas
Projeto de construção de um ambiente analítico para uma empresa fictícia do setor varejista.

- Modelagem dimensional de dados.
- Construção de processos ETL.
- Desenvolvimento de consultas gerenciais.
- Aplicação de operações OLAP, incluindo CUBE e ROLLUP.

**Tecnologias:** SQL Server, PostgreSQL e SQL.

### 📚 Sistema de Biblioteca
Aplicação para gerenciamento de informações de uma biblioteca, utilizando conceitos de desenvolvimento back-end e persistência de dados.

**Tecnologias:** Java, Spring Boot e MySQL.
